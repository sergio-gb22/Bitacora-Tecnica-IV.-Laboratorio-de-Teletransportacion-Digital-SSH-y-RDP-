# *Tarea 1:* El Escudo Legal

## Apache Guacamole
<img width="802" height="900" alt="Captura" src="images3\Apache_Guacamole_logo.png" />

Apache Guacamole es un proyecto de código abierto gratuito que se compone de varias partes, todas ellas bajo la licencia permisiva Apache License, Version 2.0 [1]

## OpenSSH
<img width="802" height="900" alt="Captura" src="images3\OpenSSH_logo.png" />

Open SSH se trata de una licencia libre y permisiva que permite su uso, modificación y distribución. Todos los componentes están bajo licencia BSD[2]

## PostgreSQL
<img width="802" height="900" alt="Captura" src="images3\Postgresql_elephant.svg.png" />

PostgreSQL se distribuye bajo la Licencia PostgreSQL , una licencia de código abierto permisiva, similar a las licencias BSD o MIT[3]
